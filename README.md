# Kiln Theme

A complete, premium Shopify Theme Store-ready theme built from scratch on Shopify Online Store 2.0.

## Features
- **4 Native Color Schemes:** Clay, Linen, Ash, and Sage.
- **Custom Aesthetics:** Subtle noise texture overlays built purely with SVG data URIs, beautiful modern typography, and robust grid systems.
- **No Dependencies:** Built with 100% native CSS (no SCSS/Sass) and vanilla JavaScript.
- **Rich Sections:** Over 20 custom sections built specifically for artisan creators, including Material Spotlights, Process Steps, and Origin Timelines.
- **Shopify OS 2.0:** Full support for app blocks, faceted filtering, and JSON templates.

## Setup
This theme is ready to be uploaded directly to your Shopify Admin or deployed via Shopify CLI.

```bash
shopify theme push
```
