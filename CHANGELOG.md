# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-08

### Added
- Initial release of the Kiln theme.
- Core architecture based on Shopify Online Store 2.0.
- 4 native color schemes (Clay, Linen, Ash, Sage).
- Custom noise texture overlay implemented natively via SVG data URI.
- Comprehensive set of JSON templates for pages, products, collections, blogs, and cart.
- Rich library of sections including:
  - Header & Footer
  - Announcement bar
  - Studio Hero
  - Featured Product
  - Collection Grid
  - Product List
  - Origin Timeline
  - Material Spotlight
  - Process Steps
  - Testimonials
  - Blog Feed
  - Newsletter
  - Logo List
  - Press Strip
  - Map
  - Image Banner
  - Image with Text
  - Rich Text
  - Slideshow
  - Custom Liquid
- Fully responsive CSS foundation without preprocessors (No SCSS/Sass).
- Vanilla JavaScript utilities.
- Accessible and semantic markup.
- SEO and JSON-LD structured data snippets.
